# FNAF1 PS1 demake — PC EXE host (no PS1 hardware limits)

Pygame build with **original FNAF-style mouse controls**.
Assets load from `fnaf_files_for_py` without VRAM/SPU/CD caps.

## Run
```bat
pip install pygame-ce
python main.py
```

## Build EXE
```bat
build_exe.bat
```
Output copied to `%USERPROFILE%\Downloads\Fnaf1PS1Exe\`
