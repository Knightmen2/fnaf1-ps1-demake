DuckStation playable package
============================

1. Install DuckStation and set a PS1 BIOS.
2. File -> Open -> select fnaf1.cue in THIS folder.
3. Keep fnaf1.bin next to fnaf1.cue.
4. Controls: KEYBOARD.txt

This is the real PS1 demake ISO (MODE2/2352), not the Windows EXE.
Source to rebuild: ../original_ps1/
