# FNAF 1 PS1 Demake (PSn00bSDK)

Open-source demake of Five Nights at Freddy's 1 for original PlayStation 1 hardware / DuckStation.

## Build
Requires [PSn00bSDK](https://github.com/Lameguy64/PSn00bSDK) and CMake.

```bat
cmake --preset default
cmake --build build
```

Output: `build/fnaf1.cue` + `build/fnaf1.bin`.
